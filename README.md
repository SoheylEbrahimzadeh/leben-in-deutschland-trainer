## 🎯 What is this?

This is not just a collection of exam questions.

It is a **learning engine** designed to help users prepare for the German **Leben in Deutschland / Einbürgerungstest** through:

- Active recall
- Adaptive learning
- Mistake-based prioritization
- Bilingual German + Persian learning
- Mock examinations
- Progress tracking
- Hessen-specific preparation
- Offline-first functionality
- Optional cloud synchronization
